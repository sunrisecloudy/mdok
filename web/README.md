# mdok promotional site

This is a dependency-free static site. Open `index.html` directly or serve the
folder while developing:

```sh
python3 -m http.server 8080 --directory web
```

The page uses local HTML, CSS, inline SVG, and a small vanilla JavaScript file;
there is no package manager or build step. Product language is grounded in the
repository README and `mdok-prd/docs`.
